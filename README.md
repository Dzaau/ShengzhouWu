This repository contains Python and R code for the manuscript _Adaptive cue reweighting during bilingualism-induced loss of checkedness in Shengzhou Wu Chinese_.

To safeguard the participants’ sensitive biometric information and comply with the terms of the informed consent agreements, the raw data, including audio recordings, annotations, and extracted acoustic and physiological parameters, are not deposited in this repository. Researchers interested in these materials may contact the first author (anonymous before acceptance) to request access for reasonable academic purposes.
